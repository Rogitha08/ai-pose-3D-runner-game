# 🎮 AI Pose 3D Runner Game

An interactive 3D runner game that uses real-time body pose detection to create a motion-controlled gaming experience. Players can interact with the game using their body movements through a webcam.

## 🚀 Features

- **Real-Time Camera Input:** Uses a webcam to capture player movements.
- **AI-Based Pose Detection:** Detects body poses using a trained machine learning model.
- **3D Gaming Experience:** Provides an interactive 3D runner game environment.
- **Motion-Based Controls:** Enables players to control gameplay using body movements.
- **Interactive Gameplay:** Combines computer vision, AI, and gaming.

## 🛠️ Technologies Used

- Python
- HTML
- CSS

- Computer Vision

- Teachable Machine Pose Model

## ⚙️ Getting Started

### Prerequisites

- Python installed on your computer
- Visual Studio Code
- A webcam
- A modern web browser
- A trained pose model and its required model files

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Rogitha08/ai-pose-3D-runner-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ai-pose-3D-runner-game
   ```

3. Open the project in Visual Studio Code:

   ```bash
   code .
   ```

4. Install any Python dependencies required by the project.

5. Start the application using the project's configured run method.

   **Note:** If the game uses browser camera access or locally hosted model files, run it through a local development server and ensure the model paths are configured correctly.

## 🎯 How to Play

1. Open the game in your browser.
2. Allow webcam access when prompted.
3. Stand where your body is visible to the camera.
4. Perform the supported body movements to control the game.
5. Avoid obstacles and enjoy the gameplay!

*Actual controls depend on the pose classes and game logic implemented in the project.*
